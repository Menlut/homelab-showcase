# Mealie — Recipes

Recipe management with its own PostgreSQL database.

[Compose configuration](docker-compose.yml) · [Environment variables](.env.example)

To prepare a local configuration:

```bash
cp .env.example .env
```

Fill in the required values before starting containers. `.env` is ignored by Git; **never commit populated credentials**.

## Before starting

- External networks: `database-admin-network` (Postgres) and `ai-services-network` (Mealie).
- The shared network(s) must exist on the Docker host before deployment.
- Web: `mealie.example.com` → `127.0.0.1:9925`; **native Authentik OIDC**.
- Keep recipe files at `MEALIE_DATA_PATH` and the database in `./mealie-postgres-data`.

## Authentik SSO

[Authentik integration guide — Mealie](https://integrations.goauthentik.io/documentation/mealie/). Use the guide for Mealie’s OIDC application/provider, redirect URIs and group mapping.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `TZ` | Timezone for application timestamps and schedules. |
| `MEALIE_BASE_URL` | Public Mealie URL used for links and SSO callbacks. |
| `MEALIE_DATA_PATH` | Host directory for Mealie uploads and data. |
| `MEALIE_DEFAULT_GROUP` | Initial default recipe group. |
| `MEALIE_DEFAULT_HOUSEHOLD` | Initial default household. |
| `MEALIE_DB_NAME` | PostgreSQL database name. |
| `MEALIE_DB_USER` | PostgreSQL account name. |
| `MEALIE_DB_PASSWORD` | PostgreSQL password; keep consistent with existing database. |
| `MEALIE_URL` | Local Mealie API URL used by companion integrations (not referenced by Compose). |
| `MEALIE_TOKEN` | Optional Mealie API token for integrations (not referenced by Compose). |
| `MEALIE_OIDC_CONFIGURATION_URL` | Authentik discovery URL for Mealie OIDC. |
| `MEALIE_OIDC_CLIENT_ID` | OIDC client ID from the Authentik provider. |
| `MEALIE_OIDC_CLIENT_SECRET` | OIDC client secret from the Authentik provider. |

## Setup and credentials

Create the Mealie OIDC client in **Authentik Admin** and enter its client ID/secret. For a *new* PostgreSQL database, generate its password locally:

```bash
openssl rand -hex 32
```

Keep the existing password when reusing a database; `MEALIE_TOKEN` is an optional Mealie-issued integration token, not a value generated by OpenSSL.

## Deploy / check

```bash
cd /home/homelab/docker/applications/mealie
docker compose config --quiet
docker compose up -d --pull never
docker compose ps
```
